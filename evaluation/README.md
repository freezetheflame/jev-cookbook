# 评估请求设计

本目录提供评估协议与标注数据格式，尚无实测模型指标。

## 数据格式

[samples.jsonl](samples.jsonl) 是三条合成数据，只演示格式，不足以评估性能：

```json
{"uid":"demo-001","split":"dev","state":{"text":"Example"},"gold":{"label":"other"}}
```

`gold` 只给评估程序使用，不能送给 Jev。程序只用选定请求模板的 questions 与样本 state 构造请求。uid 保存到本地记录，无需为识别样本而加入模型材料。

## 实验记录

每次实验保存：数据来源/版本、划分、UID、问题模板 hash、实际响应 model、阈值、全部概率/置信度、耗时、usage、失败与重试次数。不要只保存最后动作。

推荐配对实验：

| 变量 | 两组对照 |
|---|---|
| state | 拼接文本 / 命名 JSON；完整材料 / 相关窗口 |
| 目标 | 仅 ID 引用 / 附目标短文本 |
| criteria | 名称 / 单句描述 / 含排除边界和案例 |
| 组合 | 单个复合问 / 原子问题后代码组合 |
| 稳定性 | 固定语义下重排候选、同义改写、近义干扰项 |

## 指标

- 分类：每类 precision/recall、混淆矩阵、自动覆盖率、覆盖部分的错误率。
- 筛选：必要材料误删率、节省量、后续任务成功率。
- 定位：目标 span 精度与召回、邻行误报。
- 路由：最终任务成功率、降级错误、修正成本、总延迟。
- 可靠性：失败比例、回退次数、漏失输出、截断与未评估比例。

开发/验证集上确定阈值，再固定到留出集；小样本结论注明样本数。人工标注覆盖低与高 confidence 区间。比较语言时分别报告中文与英文表现。

暂时不要把 `samples.jsonl` 或合成示例的预期标签当真实基准证据。
